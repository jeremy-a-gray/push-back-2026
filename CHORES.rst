========
 Chores
========

Robotics lab chores.  Complete daily or weekly as appropriate.

Daily
=====

#. Check repository `issues <https://github.com/jeremy-a-gray/push-back-2026/issues>`_.
#. Update notebook.
#. Reset field.
#. Return unused parts to the sorting bin.
#. Store tools.
#. Charge batteries.

Weekly
======

#. Update notebook.
#. Vacuum field.
#. Sort and store unused parts in the correct bins.
#. Erase and clean boards with board cleaner.  Move important
   documentation to the engineering notebook, the issue tracker, or
   scratch paper.
