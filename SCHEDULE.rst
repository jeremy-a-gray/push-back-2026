==========
 Schedule
==========

* Monday

  * BE Period assignments
  * weekly design and planning

    File and implement an engineering cycle issue for the weekly
    improvements.

  * construction
  * coding and testing
  * update notebook and control chart

* Tuesday

  * construction
  * coding and testing
  * update notebook and control chart

  Continue building, programming, testing, and documenting the new
  improvements.

* Wednesday

  * drive testing (with and without field control)
  * autonomous testing (with and without field control)
  * finalize any construction or code fixes
  * update notebook and control chart

  Record problems as new engineering cycle issue and plan for the next
  cycle.

* Thursday

  * drive practice (with and without field control)
  * autonomous testing (with and without field control)
  * finalize any construction or code fixes
  * update notebook and control chart

  Record problems as new engineering cycle issue and plan for the next
  cycle.

* Friday

  * drive practice (with and without field control)
  * autonomous testing (with and without field control)
  * emergency construction or code fixes only
  * update notebook and control chart

  Record problems as new engineering cycle issue and plan for the next
  cycle.

Fix any bugs or design issues as they emerge (except on Fridays or
after a competetion deadline), file and implement an engineering cycle
issue, and update the notebook and control chart.
